# XENAI

مساعد ذكاء اصطناعي بواجهة عربية داكنة، سجل محادثات محلي، إدخال وإخراج صوتي، صور وملصقات، وقاعدة معرفة قابلة للتخصيص.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
cp .env.example .env
```

أضف مفتاح مزود متوافق مع واجهة OpenAI إلى `GROQ_API_KEY` داخل `.env` ثم شغّل:

```bash
npm start
```

افتح `http://localhost:3000`. مفتاح API يبقى على الخادم ولا يُرسل إلى المتصفح. لا تضع المفاتيح في ملفات الواجهة أو GitHub. إذا كان مفتاح قد نُشر سابقًا، أبطله من لوحة المزود وأنشئ مفتاحًا جديدًا.

## تخصيص المعرفة («تدريب» قاعدة المعرفة)

أضف عنصرًا لكل سطر في `data/training.jsonl` بصيغة JSON:

```json
{"title":"سياسة الاسترجاع","content":"يمكن استرجاع المنتجات خلال 14 يومًا مع الإيصال."}
```

ثم نفّذ `npm run train` لإعادة بناء `data/knowledge.json`. يبحث XENAI في هذه المعرفة ويرسل المقتطفات ذات الصلة مع السؤال. هذه عملية إعداد قاعدة معرفة محلية (استرجاع نصي)، **وليست تدريبًا أو ضبطًا دقيقًا لنموذج لغوي أساسي**. تدريب نموذج كبير فعليًا يحتاج بيانات وموارد حوسبة ومزودًا/مسار تدريب منفصلًا.

## الإعدادات

- `GROQ_API_KEY`: مفتاح المزود، مطلوب للردود.
- `XENAI_MODEL`: نموذج المحادثة النصية.
- `XENAI_VISION_MODEL`: نموذج يدعم الصور.
- `XENAI_API_URL`: اختياري لتغيير عنوان واجهة متوافقة مع OpenAI.
- `PORT`: منفذ HTTP، افتراضيًا 3000.

قد تختلف النماذج المتاحة حسب المزود والحساب؛ عيّن أسماء النماذج المدعومة في ملف `.env`. سجل المحادثات محفوظ في تخزين المتصفح المحلي. الصوت يعتمد على دعم المتصفح، ويحتاج الإملاء الصوتي عادةً إلى إذن الميكروفون واتصال آمن عند النشر.
